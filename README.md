# Perfume Price Aggregator

A Spring Boot application that aggregates perfume prices from various online stores to help users find the best deals.

## Features

- **Price Scraping**: Automatically parses prices from multiple distributors using specific parser strategies.
- **Historical Data**: Tracks price changes over time for various product sizes.
- **Currency Conversion**: Supports multiple currencies with automatic conversion.
- **Web UI**: User-friendly interface to browse perfumes and view price trends.
- **H2 Database**: Persistent storage for products, prices, and distributor info.

## Directory Structure

- `data/`: Local storage for the H2 database files.
- `src/`: Contains the application source code and resource files (HTML templates, CSS, YAML config).
- `target/`: Build artifacts and compiled classes generated by Maven.
- `pom.xml`: Maven configuration file defining dependencies and build plugins.

## Java Package Structure

The source code under `src/main/java` follows a standard Spring Boot architecture:

- `com.aggregator`: Contains the main entry point and scraping tests.
- `com.aggregator.parser`: Core scraping logic. Implements a strategy pattern with specific parsers for each distributor (e.g., `BrocardParser`).
- `com.aggregator.service`: Business logic layer handling data aggregation and processing.
- `com.aggregator.controller`: Web controllers for handling UI requests.
- `com.aggregator.entity` & `repository`: Data models and JPA persistence layer.
- `com.aggregator.dto`: Data Transfer Objects for API and UI layers.
- `com.aggregator.currency`: Logic for handling different currencies and exchange rates.
- `com.aggregator.util`: General utility classes.

## Prerequisites

- **Java**: JDK 17 or higher.
- **Maven**: 3.9.x or higher.

## How to Run

### 1. Build the project
Open a terminal in the project root and run:
`mvn clean install`

### 2. Run the application
You can start the app using Maven:
`mvn spring-boot:run`

Or by running the main class:
`src/main/java/com/aggregator/PerfumePriceAggregatorApplication.java`

### 3. Access the Application
- **Web UI**: [http://localhost:8080](http://localhost:8080)
- **H2 Console**: [http://localhost:8080/h2-console](http://localhost:8080/h2-console)
  - **JDBC URL**: `jdbc:h2:file:./data/perfume_db`
  - **User**: `sa`
  - **Password**: `sa`

## Configuration
Database settings and server port can be configured in:
`src/main/resources/application.yml`
